# 來源摘要：口說 Part 1 飛躍 31

## 來源資訊
- **原始檔案**：`SPEAKING 1 飞跃 31.pdf`（22 頁）
- **適用範圍**：IELTS Speaking Part 1（4–5 分鐘日常問答，每題約 15–25 秒、3–4 句）

## 核心摘要
- 將考官在 Part 1 的常見提問拆解為 **10 大題型模組**，讓零基礎考生不用硬背題庫，只要辨識問題開頭就能套用對應的答題骨架。

## 關鍵規則與原文例句
- **10 大題型與固定答題公式**：
  1. **Preference（喜好）**：`Answer + Reason + Frequency + Types + People/Place + Memory`
  2. **Perspective（觀點）**：`Answer + Reason + Example + Advise`
  3. **How often（頻率）**：`Answer + Reason + Example + Memory`
  4. **Where（地點）**：`Answer + Description + Feeling`
  5. **Why（原因）**：`Summary + Reason 1 + Reason 2`
  6. **When（時間）**：`Overall + Scenario 1 + Scenario 2`
  7. **Who（人物）**：`Answer + Reason + Tell a story`
  8. **Prediction（預測/假設）**：`Answer + If it happened`
  9. **Compare & Contrast（比較）**：`Overall + Object 1 + Object 2`
  10. **Importance（重要性）**：`Answer + Reason + Without + Memory`
