# AGENTS.md — IELTS 家教教學版 LLM Wiki & 現代藝廊簡報規範

> **致 AI 協作者**：這份文件參考 Andrej Karpathy 的 **LLM Wiki** 模式設計，是本專案的唯一開發與維護規範（Single Source of Truth）。目標是為**零基礎雅思考生（適用一對一家教與自主複習）**，將分散的筆記、簡報、真題與官方考情編譯成可持續累積的知識庫，並產出「現代藝廊展覽風」的 7 單元 × 24 頁互動教學 HTML 簡報組。

---

## 0. Eight Core Design Decisions（建置前八大設計決策）

| 設計維度 | 本專案明確規範 |
| :--- | :--- |
| **1. 讀者是誰** | 完全沒考過雅思的零基礎學員（一對一家教教學對象），所有術語必須先轉譯成白話與生活比喻。 |
| **2. 要哪些頁面類型** | `wiki/sources/`、`wiki/topics/`、`wiki/index.md`、`wiki/log.md`、`home.html`（入口與網站使用指南）、`slides/unit1.html` ～ `slides/unit7.html`。 |
| **3. 用什麼語言** | 全站與簡報一律使用**繁體中文（台灣用語）**，英文例句保留原文並附中文翻譯與考點說明。 |
| **4. 出處要多細** | **簡潔版**：簡報每頁底部僅標註 `wiki/` 頁面名稱（例如 `Source: wiki/topics/writing-task1.md`）；主題頁內引用外部官方考情須附可點擊 URL。 |
| **5. 資料互相矛盾怎麼辦** | **自動合併去重並記錄勘誤**：由 AI 自動合併重複檔案、修正題幹誤植，並在 `wiki/log.md` 留下 `[fix]` 勘誤紀錄。 |
| **6. 一次一篇還是批次** | **一次一篇慢慢 `/ingest`**：每次只處理一篇原始檔案，先建立來源摘要，再整合進主題頁並更新索引。 |
| **7. 之後要產出什麼** | 給零基礎學員上課使用的 **7 個獨立單元 × 各 24 頁（共 168 頁）現代藝廊風互動教學簡報**與入口頁（`home.html`）。 |
| **8. `/lint` 要檢查什麼** | 重點檢查 **(1) 新手術語是否已轉成白話**、**(2) 來源間的說法衝突與重複內容**、**(3) YAML Frontmatter 與 `[[雙向連結]]` 完整性**。 |

## 1. Project Architecture（三層架構）

├── AGENTS.md                 # Layer 3: Schema（八大決策、四大擴充規範與 Loop/Graph）

## 2. Special Commands（特別觸發指令）
- **`/ingest <單篇檔案>`**：讀取單一原始檔 → 寫入 `wiki/sources/` → 整合進 `wiki/topics/` → 更新 `index.md` & `log.md`。
- **`/lint`**：檢查 `BEGINNER_CHECK`、來源衝突重複、YAML Frontmatter 與 `[[雙向連結]]`（≥ 2 個）。
- **`/build-slides`**：確認 Gate 1 通過後，僅讀取 `wiki/` 產出 7 個單元 × 24 頁簡報。

---

## 3. Mandatory Guardrails（強制規範與檢查閘門）
1. **`STRICT_WIKI_ONLY`**：簡報內容必須源自 `wiki/`，每頁底部標註 `Source: wiki/topics/<name>.md`。
2. **`LINT_BEFORE_SLIDES`**：`wiki/log.md` 須先有最近一次 `[lint]` 通過紀錄。
3. **`BEGINNER_CHECK`**：所有考場縮寫與術語須附白話解釋。
4. **`SLIDE_DENSITY_LIMIT`**：每頁最多 3 個資訊區塊，維持 35% 以上留白呼吸感。

---

## 4. Expanded Rule Modules（四大進階執行模組）

### 模組 A：Wiki 頁面強制模板
- 所有 `wiki/sources/*.md` 與 `wiki/topics/*.md` 須具備 YAML Frontmatter（`title`、`type`、`tags`、`updated`、`sources`）、必備章節與至少 **2 個 `[[雙向連結]]`**。

### 模組 B：現代藝廊展覽風美學與互動教學工具規範
1. **高反差單一強調色盤**：
   - **背景主色**：冷白紙感 `#F5F6F8`（畫布底）、純白 `#FFFFFF`（內容卡）。
   - **文字主色**：濃黑 `#111111`（大標題）、深炭灰 `#3A3F4B`（正文）、輔助灰 `#6B7280`（頁碼與註腳）、細框線 `#E2E5EB`。
   - **唯一強調色**：**國際克萊因藍 `#002FA7`**（標籤、重點邊框、進度條、SVG 插畫與重點標記）。
2. **雜誌排版與留白呼吸感**：
   - 大留白邊距、不對稱網格、巨型襯線頁碼水印（`01`–`24`）、客製極簡單線幾何 SVG 插畫。
3. **互動教學工具（底部懸浮膠囊 Dock ＋ 工具使用提示）**：
   - **游標／選字（預設）**：反白任何英文單字即跳出浮動氣泡，可一鍵套用 **3 色螢光筆（柔黃／薄荷／淡藍）**，並點擊 **「查劍橋字典」** 另開分頁直達 `https://dictionary.cambridge.org/dictionary/english/<word>`。
   - **雷射筆**：滑鼠化為柔和發光指示點，協助講解帶視線。
   - **自由畫筆 ＋ 清空**：可在投影片上圈畫板書，換頁或重整自動清空（單次教學模式）。
   - **工具提示機制**：`home.html` 須設有「如何使用這個網站」專區，每份簡報頂部或 Dock 旁亦須提供簡潔「工具提示」說明。

### 模組 C：7 單元 × 每單元 24 頁架構
- 每個單元皆採 **24 頁深度節奏**：導論破題 → 核心規則與 2025 真題／筆記實例 → NG vs. 高分實戰對比 → 檢核表，確保單頁不擁擠且內容詳盡。

### 模組 D：Loop 錯誤退回與防呆條件表

| Loop 節點 | 失敗／異常觸發條件 | 退回目標節點 | 強制修正動作 |
| :--- | :--- | :--- | :--- |
| **Gate 1: `/lint`** | 術語未白話、缺 Frontmatter 或連結 < 2 | 退回 `wiki/` 編輯 | 補齊並寫入 `log.md` `[fix]` 後重跑 |
| **Gate 2: `BEGINNER_CHECK` + `DENSITY`** | 出現未解釋術語或單頁超過 3 區塊 | 退回「拆頁重組」 | 拆分為兩頁維持留白 |
| **Gate 3: 工具與路徑驗收** | 劍橋字典/螢光筆/雷射筆異常或路徑斷裂 | 退回 HTML 修補 | 修正 JS 與相對路徑後複驗 |
